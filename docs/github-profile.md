## 正在做的项目

**[Local Billing Workspace｜本地开票工作台](https://github.com/josephinexyy/local-billing-workspace)**

从自己的开票需求出发，将客户、业务、形式发票、正式发票和收据串成一套操作流程。支持 HKD / USD、PDF 导出、三语界面、本地客户资料识别与备份合并。

我负责需求梳理、业务规则与产品迭代，使用 AI 辅助实现，并在项目中说明目前的功能边界。
