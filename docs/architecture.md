# 代码结构与修改入口

页面使用普通脚本，维持直接文件及静态服务的使用方式。纯模块同时提供 CommonJS 导出，Node 测试直接调用公开函数，不截取源码片段。

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| company.js | 默认演示配置、公司字段与时区校验 | 页面、存储写入 |
| core.js | 精确金额输入、年度编号、开单、收款、取消、快照及冲突 | DOM、PDF、浏览器 API |
| storage.js | 锁内重新读取、校验与保存；升级留底 | 决定票面样式 |
| backup.js | v1 / v2 解码、v3 完整备份与恢复计划 | 文件选择窗口 |
| documents.js | 显式输入的票面 HTML、转义和不切断文字行的分页边界 | 读取当前公司设置或保存记录 |
| customer-tools.js | 字体等待、浏览器栅格化、多页 PDF 与 ZIP | 业务状态变化 |
| app.js | 表单、页面与模块协调，处理用户反馈 | 重新实现编号和备份规则 |

调整票面：修改 `documents.js`，运行模板、转义及浏览器 PDF 测试，再重建离线文件。调整收款或编号：修改 `core.js`，覆盖重复提交和双标签页情形。调整本地保存：修改 `storage.js`，覆盖配额失败、损坏数据及升级前留底。新增备份格式：在 `backup.js` 明确兼容规则并验证旧样例。

`app.js` 仍使用原生 DOM，尚未拆成组件。后续可以按表单或页面继续拆分，本次优先把业务规则、存储与票面隔离。第三方压缩库及模型文件保留原样。
